# Contributing to Event Booking Frontend

Thanks for helping improve this project! Please follow these steps.

## How to contribute

1. Check the open issues, or open a new issue to describe the bug or feature before you start.
2. Create a branch from the latest `main`:
   ```bash
   git checkout -b feature/short-description
   ```
3. Make your change in small commits with clear messages, for example `Add validation to booking form`.
4. Run the app and the tests locally before you push.
5. Push your branch and open a pull request that explains what changed and links the issue (for example `Closes #12`).
6. Respond to review comments. A maintainer merges the pull request once it is approved.

## Rules

- Never commit directly to `main`.
- Never commit secrets or `.env` files; they are listed in `.gitignore`.
- Keep pull requests small and focused on one change.
- Be respectful and constructive in reviews and discussions.
